# WP Travel Kit plugins for Claude Code

A plugin marketplace. Add it once, then install plugins from it:

```
/plugin marketplace add tajim/wptravelkit-design-plugins
/plugin install design-to-blocks@wptravelkit
```

| Plugin | What it does |
|---|---|
| [design-to-blocks](plugins/design-to-blocks/README.md) | Claude Design export -> tested block pages, patterns and a Travelscape child theme |
