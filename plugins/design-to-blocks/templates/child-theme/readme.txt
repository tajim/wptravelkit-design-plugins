== Description ==

Travel Royale is a block-based child theme of Travelscape for luxury travel agencies, private tour designers and tailor-made trip planners. It comes with a full-screen hero with trip search, signature destination grids, curated journeys powered by WP Travel Engine, experience and perk cards, a "how we plan" section, traveler reviews and a consultation call-to-action. Every page is made with native WordPress blocks.

Requires the Travelscape parent theme. Recommended plugins: WP Travel Engine, Contact Form 7 and Demo Importer Plus.

== Installation ==

1. Install and activate the Travelscape parent theme.
2. Upload Travel Royale, then go to Appearance > Themes and activate it.
3. For the full demo, install Demo Importer Plus and import the Travel Royale demo.

== Frequently Asked Questions ==

= How do I make a page look like the demo? =

Create a page, choose the "Block Canvas" template, then insert one of the Travel Royale page patterns.
